# Dashboard Usage Guide

### 1. Install Dependencies
Make sure you have Streamlit and Pandas installed:
```bash
pip install streamlit pandas
```

### 2. Configure Data Path
Download `my_app.py`, open it in an editor, and update the `data_path` variable to match your local file location:

```python
# Change this to your actual local file path
data_path = "C:/your/local/path/data.csv"
```

### 3. Run the App
Execute the following command in your terminal:

```bash
streamlit run my_app.py
```

### 4. Access the Dashboard
The dashboard will open in your browser at [http://localhost:8501](http://localhost:8501).
