## 一、输出文件总览

运行 `preprocess.ipynb` 后，`processed/` 目录下会生成以下文件：

| 文件 | 大小（估计） | 用途 |
|------|------------|------|
| `tensor.npy` | ~147 MB | 核心数据，所有模型的基础 |
| `time_features.npy` | ~0.7 MB | 每个时间步的时间特征（sin/cos 编码等） |
| `meta.json` | ~几 MB | 元信息：网格数、切分边界、犯罪类型等 |
| `events_train.parquet` | ~几十 MB | 事件级训练集（XGBoost / FlexiCrime 用） |
| `events_val.parquet` | — | 事件级验证集 |
| `events_test.parquet` | — | 事件级测试集 |

## 二、核心文件详解

### 2.1 `tensor.npy` — 犯罪计数张量

**形状：`(N_STEPS, N_GRIDS, N_TYPES)`**

```
tensor[t, g, c] = 在时间步 t，网格 g 中，犯罪类型 c 发生的案件数（整数）
```

| 维度 | 含义 | 实际值 |
|------|------|--------|
| `N_STEPS` | 总时间步数（约10年 × 每天6槽） | ~21858 |
| `N_GRIDS` | 有犯罪记录的有效网格数 | ~674 |
| `N_TYPES` | 犯罪类型数（Top 5） | 5 |

**时间步的含义：**
- 每天被划分为 6 个时间槽（每槽 4 小时）
- `time_step = day_index × 6 + slot`
- 槽 0 = 22:00–02:00，槽 1 = 02:00–06:00，…，槽 5 = 18:00–22:00

**网格的含义：**
- 芝加哥市被划分为约 1km × 1km 的方格
- `N_GRIDS` 只保留至少出现过 1 次犯罪的格子
- 网格索引 `g`（0 到 N_GRIDS-1）与地理位置的对应关系存储在 `meta.json` 中

**5 种犯罪类型（按频率排序）：**

```
索引 0 → THEFT（盗窃）
索引 1 → BATTERY（伤害）
索引 2 → CRIMINAL DAMAGE（财产破坏）
索引 3 → ASSAULT（袭击）
索引 4 → DECEPTIVE PRACTICE（欺诈）
```

> **注意**：使用张量前建议做对数变换 `log(count + 1)`，因为犯罪计数分布重尾且零值多。

---

### 2.2 `time_features.npy` — 时间特征表

**形状：`(N_STEPS, 8)`**

每一行对应一个时间步，8 列含义如下：

| 列索引 | 列名 | 含义 | 取值范围 |
|--------|------|------|---------|
| 0 | `slot_sin` | 时间槽的正弦编码 | -1 ~ 1 |
| 1 | `slot_cos` | 时间槽的余弦编码 | -1 ~ 1 |
| 2 | `weekday_sin` | 星期几的正弦编码 | -1 ~ 1 |
| 3 | `weekday_cos` | 星期几的余弦编码 | -1 ~ 1 |
| 4 | `month_sin` | 月份的正弦编码 | -1 ~ 1 |
| 5 | `month_cos` | 月份的余弦编码 | -1 ~ 1 |
| 6 | `is_weekend` | 是否周末 | 0 或 1 |
| 7 | `is_holiday` | 是否伊利诺伊州法定节假日 | 0 或 1 |

> 为什么用 sin/cos 编码而不是直接用数字？
> 因为时间是循环的（周日之后是周一，12月之后是1月）。直接用数字（0~6）会让模型误以为周日（6）和周一（0）相差很远。sin/cos 编码保证了周期边界的连续性。

---

### 2.3 `meta.json` — 元信息

常用字段说明：

```json
{
  "n_grids"  : 674,       // 有效网格数
  "n_types"  : 5,         // 犯罪类型数
  "n_steps"  : 21858,     // 总时间步数
  "lookback" : 180,       // 历史窗口长度（30天 × 6槽）
  "train_end": 17523,     // 训练集结束的时间步（不含）
  "val_end"  : 19690,     // 验证集结束的时间步（不含）
  "n_rows"   : 43,        // 网格行数（南北方向）
  "n_cols"   : 35,        // 网格列数（东西方向）
  "crime_types": ["THEFT", "BATTERY", ...],  // 犯罪类型名称列表
  "active_grids": [...],  // 每个网格索引 g 对应的原始 grid_id
  "grid_remap"  : {...},  // 原始 grid_id → 压缩后的网格索引 g
  "lat_min", "lon_min", "grid_lat", "grid_lon"  // 坐标系参数
}
```

**三段切分边界（最重要的字段）：**

```
训练集输入范围：tensor[0 : train_end]
验证集输入范围：tensor[train_end - lookback : val_end]     ← 向前多取 lookback 步作为输入窗口
测试集输入范围：tensor[val_end - lookback : ]              ← 同上

训练集预测目标：time_step in [lookback, train_end)         → 共约 17343 步
验证集预测目标：time_step in [train_end, val_end)          → 共约 2168 步
测试集预测目标：time_step in [val_end, n_steps)            → 共约 2168 步
```

### 2.4 `events_*.parquet` — 事件级数据

每一行是一条犯罪事件记录。列说明：

| 列名 | 含义 |
|------|------|
| `time_step` | 全局时间步索引 |
| `slot` | 时间槽（0–5） |
| `weekday` | 星期几（0=周一，6=周日） |
| `month` | 月份（1–12） |
| `is_weekend` | 是否周末（0/1） |
| `is_holiday` | 是否节假日（0/1） |
| `slot_sin/cos` | 时间槽循环编码 |
| `weekday_sin/cos` | 星期循环编码 |
| `month_sin/cos` | 月份循环编码 |
| `Latitude` | 纬度 |
| `Longitude` | 经度 |
| `grid_row` | 网格行号 |
| `grid_col` | 网格列号 |
| `grid_id` | 原始网格 ID（= grid_row × n_cols + grid_col） |
| `crime_type` | 犯罪类型索引（0–4） |
| `Primary Type` | 犯罪类型名称 |

## 三、各模型如何使用数据

### LSTM （序列模型）

**推荐方式：用 `CrimeDataset` 按需生成窗口，不要手动展开**

```python
import numpy as np
from utils import load_data, CrimeDataset
from torch.utils.data import DataLoader

tensor, time_features, meta = load_data("processed")

lookback   = meta["lookback"]    # 180
train_end  = meta["train_end"]   # ~17523
val_end    = meta["val_end"]     # ~19690
n_steps    = meta["n_steps"]     # ~21858

# 创建 Dataset
ds_train = CrimeDataset(tensor, time_features, start=lookback,    end=train_end, lookback=lookback)
ds_val   = CrimeDataset(tensor, time_features, start=train_end,   end=val_end,   lookback=lookback)
ds_test  = CrimeDataset(tensor, time_features, start=val_end,     end=n_steps,   lookback=lookback)

# 创建 DataLoader
loader_train = DataLoader(ds_train, batch_size=32, shuffle=True)

# 每个 batch 的内容：
for x_seq, x_time, y in loader_train:
    # x_seq  : (batch, 180, 674, 5)  — 过去180步的犯罪计数，已做 log(x+1) 变换
    # x_time : (batch, 180, 8)       — 对应的时间特征
    # y      : (batch, 674, 5)       — 要预测的下一步犯罪计数，已做 log(x+1) 变换
    pass

# 评估时注意反变换：预测值 → np.expm1(pred) 还原为实际计数
```

### XGBoost （树模型）

**推荐方式：用 `build_lag_features` 为每个 (时间步, 网格) 构建特征向量**

```python
import numpy as np
import pandas as pd
from utils import load_data, build_neighbor_matrix, build_lag_features

tensor, time_features, meta = load_data("processed")

lookback  = meta["lookback"]
train_end = meta["train_end"]
N_GRIDS   = meta["n_grids"]
N_TYPES   = meta["n_types"]

# 预计算所有网格的邻居（只算一次）
neighbor_list = build_neighbor_matrix(meta)

# 构建训练集特征矩阵
rows = []
for t in range(lookback, train_end):          # 遍历每个时间步
    tf = time_features[t]                     # 当前时间步的8个时间特征
    for g in range(N_GRIDS):                  # 遍历每个网格
        lag_feats = build_lag_features(tensor, t, g, neighbor_list)  # 滞后+邻域特征
        feat_row  = np.concatenate([tf, lag_feats])
        target    = tensor[t, g, :]           # 5种犯罪类型的真实计数
        rows.append((feat_row, target))

# 训练
# X_feat: (N_samples, n_features)
# y_flat: (N_samples, N_TYPES) — 可以拆成5个独立模型，每个预测一种犯罪类型
```

> **提示**：遍历所有 (时间步 × 网格) 对数量很大（~17343 × 674 ≈ 1170万行），
> 建议先用随机采样测试模型，再全量训练，或对每种犯罪类型分别训练一个模型。

### ST-GCN（时空图卷积网络）

ST-GCN 需要两样东西：① 和 LSTM 一样的时序特征张量，② **图结构**（哪些网格之间有边）。

**第一步：构建邻接矩阵**

```python
import numpy as np
import torch
from utils import load_split_data, build_neighbor_matrix, CrimeDataset
from torch.utils.data import DataLoader

splits, meta = load_split_data("processed")
lookback = meta["lookback"]
N_GRIDS  = meta["n_grids"]

# 构建稀疏邻接矩阵 A，shape: (N_GRIDS, N_GRIDS)
# A[i, j] = 1 表示网格 i 和网格 j 是 8-连通邻居
neighbor_list = build_neighbor_matrix(meta)

A = np.zeros((N_GRIDS, N_GRIDS), dtype=np.float32)
for g, neighbors in enumerate(neighbor_list):
    for nb in neighbors:
        A[g, nb] = 1.0
    A[g, g] = 1.0   # 自环

# 归一化（度矩阵归一化，GCN 标准做法）
degree = A.sum(axis=1, keepdims=True)
degree[degree == 0] = 1
A_norm = A / degree

A_tensor = torch.from_numpy(A_norm)   # 固定图结构，每个 batch 共用
```

**第二步：Dataset 与 LSTM 完全相同**

```python
ds_train = CrimeDataset(splits["tensor_train"], splits["time_features_train"],
                        start=lookback, end=splits["tensor_train"].shape[0], lookback=lookback)
ds_val   = CrimeDataset(splits["tensor_val"],   splits["time_features_val"],
                        start=lookback, end=splits["tensor_val"].shape[0],   lookback=lookback)
ds_test  = CrimeDataset(splits["tensor_test"],  splits["time_features_test"],
                        start=lookback, end=splits["tensor_test"].shape[0],  lookback=lookback)

loader_train = DataLoader(ds_train, batch_size=16, shuffle=True)
```

**第三步：模型 forward 时的数据格式**

```python
for x_seq, x_time, y in loader_train:
    # x_seq  : (batch, 180, 674, 5)  — 时序犯罪计数，log(x+1) 变换后
    # x_time : (batch, 180, 8)       — 时间特征
    # y      : (batch, 674, 5)       — 预测目标，log(x+1) 变换后
    # A_tensor: (674, 674)           — 邻接矩阵，训练全程固定不变

    # ST-GCN 通常将节点特征定义为 (batch, T, N_nodes, in_channels)
    # 其中 in_channels = N_TYPES(5) 或 N_TYPES + 时间特征维度
    # 具体拼接方式由模型结构决定
    pass
```

> **关于边的权重**：上面用的是 0/1 邻接 + 度归一化。如果想用距离加权（越近权重越大），
> 可以用两网格中心点的欧氏距离的倒数作为权重

## 四、评估对齐（重要！）

**所有模型必须在相同的时间段上比较**，否则结果没有可比性。

| 集合 | 预测目标 time_step 范围 | 对应 tensor 切片 |
|------|------------------------|-----------------|
| 验证集 | `[train_end, val_end)` | `tensor[train_end : val_end]` |
| 测试集 | `[val_end, n_steps)` | `tensor[val_end :]` |

评估指标统一在**反变换后的原始计数**上计算：
```python
pred_count = np.expm1(model_output)   # 如果模型用了 log(x+1)
true_count = tensor[val_end:]

mae  = np.mean(np.abs(pred_count - true_count))
rmse = np.sqrt(np.mean((pred_count - true_count) ** 2))
```

## 五、utils.py 函数速查

| 函数 | 用途 | 适用模型 |
|------|------|---------|
| `load_data(out_dir)` | 加载完整 tensor、time_features、meta | 所有模型 |
| `load_meta(out_dir)` | 只加载 meta.json | 所有模型 |
| `get_neighbors(g, meta)` | 查询单个网格的8邻居索引列表 | ST-GCN / XGBoost |
| `build_neighbor_matrix(meta)` | 预计算所有网格的邻居列表（训练前调用一次） | ST-GCN / XGBoost |
| `build_lag_features(tensor, t, g, neighbor_list)` | 为 (时间步t, 网格g) 构建滞后+邻域特征向量 | XGBoost |
| `CrimeDataset(tensor, time_features, start, end, lookback)` | PyTorch Dataset，动态生成滑动窗口 | LSTM / ST-GCN |
