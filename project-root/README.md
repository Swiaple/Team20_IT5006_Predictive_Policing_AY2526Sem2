# Team20 IT5006 Predictive Policing (AY2526 Sem 2)

This repository contains Team20's work for **IT5006 Predictive Policing** in **AY2526 Semester 2**, including data processing, exploratory analysis, model development, and dashboard visualization.

## Project Structure

```text
/project-root
├── LSTM/
├── XGboost/
├── dashboard/
├── data/
├── dataset/
├── eda/
├── references/
├── stgcn/
├── README.md
├── dashboardvideo.mp4
└── requirements.txt
```

## Folder Overview

- `LSTM/`: LSTM-based modeling and related scripts.
- `XGboost/`: XGBoost modeling and experiments.
- `stgcn/`: STGCN modeling components.
- `eda/`: Exploratory Data Analysis notebooks/scripts.
- `data/`: Processed or intermediate data files.
- `dataset/`: Raw or curated datasets used in this project.
- `dashboard/`: Dashboard source code and deployment-related files.
- `references/`: Supporting materials, papers, and references.

## Setup

1. Create and activate a Python environment.
2. Install dependencies:

```bash
pip install -r requirements.txt
```

## Dashboard Video Note

Due to computational resource limitations on the deployed web platform, some dashboard computations are difficult to run smoothly online.  
Therefore, we provide **`dashboardvideo.mp4`** as a reference demonstration of the dashboard features and outputs.
